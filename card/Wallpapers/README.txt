# Wallpapers（壁纸）

把 `.png` 放在这里，然后在「设置 → 通用 → 壁纸」里选择。

请按屏幕尺寸制作：

  设备            尺寸
  H700            720 x 480
  RG SP           720 x 480
  RG34XX          720 x 480
  RG34XXSP        720 x 480
  RG35XXSP        640 x 480
  RG35XX Plus     640 x 480
  RG35XX-H        640 x 480
  RG28XX          640 x 480

其他尺寸会按比例缩放、从中心裁切。
